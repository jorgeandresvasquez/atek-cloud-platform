# ATEK — Technical Director Interview Assessment

## Congratulations!

Following our initial discussions, we are pleased to invite you to the next phase of our **Technical Director interview process** at **ATEK**.

This phase consists of a **technical assessment** designed to evaluate your approach to modern software development, your strategic thinking, and your ability to leverage emerging technologies in a regulated environment.

We believe this practical assessment will provide valuable insights into how you would contribute to our mission of delivering **safe, compliant, and efficient monitoring solutions** for critical environments.

---

## Assessment Context

At **ATEK**, we evaluate your ability to structure **modern development environments** that intelligently leverage **AI tools** to generate robust, maintainable, and scalable code.

This assessment evaluates three critical dimensions:

1. **Technical Competence:** Mastery of software architecture and design patterns.
2. **Strategic Judgment:** Ability to make architectural decisions aligned with business objectives.
3. **Innovation:** Proactive use of emerging technologies (AI-assisted coding).

---

## Assessment Instructions

### Primary Deliverable

Create a **development environment** configured to generate production-quality code through AI assistance.

---

### Technical Specifications

#### 1. Public GitHub Repository

* Create a **public repository** demonstrating your approach.
* Include clear documentation (`README.md`).
* Ensure a scalable and modular project structure.

#### 2. Environment Configuration

Use Cursor, VS Code, or your preferred IDE.
Configure rules/prompts for the AI that ensure:

* Consistent application of design patterns.
* Generation of structured and maintainable code.
* Adherence to object-oriented principles.
* Self-documenting code practices.
* GAMP5-style documentation.
* FDA 21 CFR Part 11 compliance considerations.
* Unit and integration testing.

#### 3. Regulatory and Documentation Requirements

The code must demonstrate:

* **Self-documenting code:** Clear naming conventions, meaningful variable/function names, logical structure.
* **GAMP5 documentation approach:** Appropriate documentation levels based on system complexity.
* **21 CFR Part 11 compliance:** Demonstration of:

  * Audit trail capabilities.
  * Electronic signature considerations.
  * Data integrity principles.
  * Access control patterns.
* **OpenAPI 3.x compliance:** If an API is present, a full OpenAPI 3.x specification.

#### 4. Architectural Pattern Demonstration

The code must illustrate:

* Separation of concerns.
* Layered or modular architecture.
* Dependency management.
* Extensibility and scalability.
* Relevant patterns (e.g., Repository, Factory, Strategy, Observer).

#### 5. Technology Stack

* **Required:** TypeScript as the primary language.
* Leverage the **JavaScript ecosystem** (Node.js, frameworks, libraries).
* Free choice of frameworks within the JS/TS ecosystem.
* Provide **justification for technology choices** in the documentation.
